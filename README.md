# 🛍️ Products Management App (React)

یک پروژه‌ی مدیریت محصولات ساخته‌شده با **React.js**، با قابلیت افزودن، ویرایش، حذف، و جستجوی محصولات به همراه API، Context و Modal‌های زیبا.

---

## 🚀 ویژگی‌ها

- 🔍 جستجو در بین محصولات به‌صورت زنده
- ➕ افزودن محصول جدید
- ✏️ ویرایش محصول موجود
- 🗑️ حذف محصول با تأیید در Modal
- ⏳ نمایش Loader انیمیشنی هنگام بارگذاری
- 📦 مدیریت State با Context و Reducer
- 🎨 طراحی تمیز و ساختار ماژولار
